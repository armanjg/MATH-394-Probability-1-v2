DNE

Moment-Generating Function

The moment-generating function is

\[ M_X(t)=\mathbb {E}(e^{tX}). \]
When it exists near \(t=0\), it can be used to compute moments:
\[ \mathbb {E}(X^n)=M_X^{(n)}(0). \]
