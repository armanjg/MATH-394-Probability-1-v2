# Repository reorganization notes

This repository was created as a cleaned copy of the original repository. The original repository was not modified.

## Main changes

1. Consolidated source material into `source/` by purpose: lectures, homework, exams, handouts, and syllabus.
2. Consolidated figures and interactive visualizations into `assets/figures/`.
3. Merged annotated PDFs previously split between `Annotated/` and `docs/Annotated/` into `assets/annotated/` while retaining the published copies in `docs/`.
4. Moved the editable homepage to `site/index.html`; the build copies it to `docs/index.html`.
5. Moved the full build script to `scripts/build.sh` and retained a small root `build.sh` wrapper.
6. Kept `docs/` as the GitHub Pages deployment directory, but removed obvious LaTeX temporary/build files from it.
7. Added `.gitignore` for LaTeX and editor/build noise.
8. Removed redundant root-level generated `sup.html` and `sup.pdf` from the source side; their published copies remain under `docs/`.
9. Preserved existing public filenames wherever practical to reduce the chance of breaking links.

## Intentionally retained duplicates

Files may exist both under `assets/`/`source/` and `docs/`. This is intentional: the former are authoritative source assets while `docs/` is the generated website output deployed by GitHub Pages.

## Items not automatically deleted

Versioned/numbered annotated PDFs (for example `chapter4_expectation1.pdf` and `chapter4_expectation2.pdf`) were retained because filename similarity alone does not prove that the contents are redundant. Exact-byte duplicates can be reviewed separately if desired.

## Link and build fixes made in the new copy

- Corrected a malformed YouTube URL beginning with `Lhttps://`.
- Corrected the Lecture 11b HTML link to the existing Chapter 5B HTML page.
- Corrected two midterm-practice-solution links to point into `Exams/`.
- Consolidated repetitive exam build commands into one loop and added the public exam outputs that the homepage already referenced.
- HTML conversion with `make4ht` is treated as non-fatal because `distributions-v1.tex` triggers a TeX4ht DOM stack-overflow in the current toolchain; existing published HTML is retained when that conversion fails. LaTeX/PDF build errors remain fatal.
- A static check of the reorganized homepage found zero missing local links after these fixes.

See `DUPLICATE_REVIEW.md` for exact-byte duplicate annotated PDFs that require human review rather than automatic deletion.

## Generated-output deduplication

The original repository stored large generated PDFs and assets both as source material and again under `docs/`. In this cleaned repository, `docs/` is generated during the build and is not committed. Small HTML/CSS fallback snapshots are retained under `site/static/` only where useful for pages that are not reliably regenerated by the current TeX4ht toolchain. This substantially reduces repository duplication.
