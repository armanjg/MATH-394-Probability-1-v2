Why Study Probability?  
Central idea  
Mathematics is the logic of certainty. Probability is the logic of uncertainty.  
Probability provides tools for:  
▶ modeling randomness and uncertainty;  
▶ understanding variation and separating signal from noise;  
▶ making principled predictions and decisions;  
▶ quantifying risk;  
▶ avoiding misleading or incomplete intuition.  
Instructor note / optional discussion  
Ask students for examples of uncertainty from everyday life: weather, medical tests, elections, gambling,  
machine learning, stock prices, sports, or exams.

Random Experiments  
A random experiment is a process whose outcome is uncertain before it is performed.  
Examples:  
▶ ﬂipping a coin;  
▶ rolling a die;  
▶ drawing a card from a shuﬄed deck;  
▶ recording tomorrow’s temperature;  
▶ selecting a student from the class;  
▶ measuring the lifetime of a machine component.  
Important  
Before assigning probabilities, the possible outcomes must be clearly speciﬁed.

Deﬁnition: Sample Space and Event  
Deﬁnition  
The sample space S of an experiment is the set of all possible outcomes.  
An event A is a subset of the sample space:  
A ⊆ S.  
The event A occurs if the actual outcome belongs to A:  
sactual ∈ A.  
▶ An outcome is a single element of S.  
▶ An event is a collection of outcomes.  
▶ The sample space is the universal set for the experiment.  
▶ Some textbooks use Ω instead of S, and ω instead of s

The Empty Set  
The empty set is the set with no elements. It is denoted by  
∅.  
Important facts:  
▶ ∅ means “nothing occurred” or “no outcome is included.”  
▶ For every set A,  
A ∩ ∅ = ∅.  
▶ For every set A,  
A ∪ ∅ = A.  
▶ The empty set is a subset of every set:  
∅ ⊆ A.

Events as Sets: A versus {A}  
Suppose A is an event. Then A is already a set of outcomes.  
For example, if  
S = {1, 2, 3, 4, 5, 6},  
A = {2, 4, 6},  
then A is the event that the die roll is even.  
But  
ꢀ
{A} = {2, 4, 6}  
is a set whose single element is the set A.  
Common mistake  
Usually, A ⊆ S, but {A} is not a subset of S unless A itself is an outcome.

De Morgan’s Laws  
For events A, B ⊆ S,  
(A ∪ B)c = Ac ∩ Bc ,  
(A ∩ B)c = Ac ∪ Bc .  
Interpretation:  
▶ Not having at least one of A or B means having neither.  
▶ Not having both A and B means at least one fails to occur.

A Subtle Point: Is the Sample Space Correct?  
In the card example, the sample space is the set of all 52 standard cards.  
If the drawn card is a joker, then the issue is not probability calculation.  
The issue is:  
the sample space was wrong.  
Rule  
The sample space must contain every outcome that can actually occur.

Common Mistake  
Biohazard  
Do not confuse an outcome with an event.  
For one die roll:  
S = {1, 2, 3, 4, 5, 6}.  
The number 4 is an outcome.  
The event “the roll is even” is the set  
E = {2, 4, 6}.  
So:  
4 ∈ S,  
E ⊆ S.  
Optional emphasis  
Writing E ∈ S is wrong here because E is a set of outcomes, not a single outcome.

Summary  
▶ Probability begins with a clearly speciﬁed sample space S.  
▶ Outcomes are elements of S.  
▶ Events are subsets of S.  
▶ An event occurs when the actual outcome lies in that event.  
▶ Set operations allow us to build complicated events from simpler events.  
▶ De Morgan’s laws are essential tools for rewriting complements.  
▶ Choosing the correct sample space is part of the modeling process.
